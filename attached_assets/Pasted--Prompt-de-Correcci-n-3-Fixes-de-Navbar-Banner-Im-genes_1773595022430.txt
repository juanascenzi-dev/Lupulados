## 2. FIX CRÍTICO: BANNER DE OFERTA + NAVBAR STICKY

Hay un bug con el banner de la promo "10% OFF — Usá el código PRIMERABIRRA":

**Problema actual:** Cuando el usuario NO cierra el banner con la X y scrollea hacia abajo, queda un espacio vacío donde estaba el banner, y el navbar sticky deja un hueco feo arriba. También si lo cerrás con la X y scrolleás, el espacio persiste.

**Solución — implementar este comportamiento exacto:**

### Cuando el banner está VISIBLE (no lo cerró):
- El banner de oferta va fijo arriba de todo (position: fixed o sticky, top: 0, z-index alto).
- El navbar va inmediatamente debajo del banner (sticky, top: [altura del banner]).
- Al hacer scroll, **ambos quedan fijos arriba**: primero el banner, abajo el navbar. Se mueven como una unidad.
- NO debe quedar ningún espacio vacío entre el banner y el navbar.

### Cuando el usuario CIERRA el banner con la X:
- El banner desaparece con una animación suave (slide up o fade out).
- El navbar sube y ocupa top: 0 inmediatamente, sin salto ni espacio vacío.
- Guardar en `localStorage` que el usuario cerró el banner para no mostrarlo de nuevo si recarga la página.

### Implementación técnica sugerida:
```jsx
const [showBanner, setShowBanner] = useState(() => {
  return localStorage.getItem('promoBannerClosed') !== 'true';
});

const closeBanner = () => {
  setShowBanner(false);
  localStorage.setItem('promoBannerClosed', 'true');
};

// El navbar debe calcular su top dinámicamente:
// top: showBanner ? 'altura-del-banner' : '0'
```

- Usar `transition-all duration-300` para que el movimiento sea suave.
- El contenido del sitio (debajo del navbar) debe tener un `padding-top` o `margin-top` que se ajuste dinámicamente según si el banner está visible o no, para que no haya saltos en el contenido.

**IMPORTANTE**: Probar estos 3 escenarios:
1. ✅ Página carga con banner → scroll → banner y navbar quedan fijos arriba juntos, sin espacio.
2. ✅ Usuario cierra banner con X → navbar sube suavemente a top:0, contenido se ajusta, sin hueco.
3. ✅ Recarga la página después de cerrar → banner no aparece, navbar directo en top:0.

## 4. MEJORAR LA CALCULADORA — INPUTS NUMÉRICOS EDITABLES CON FLECHAS

Actualmente la calculadora usa solo sliders. Quiero que cada campo tenga **doble input**: el usuario puede escribir el número exacto O usar flechitas arriba/abajo para incrementar/decrementar. Esto es para la gente que quiere ser específica.

### Cantidad de invitados:
- Input numérico con flechas (type="number") + slider debajo como complemento visual.
- Mínimo: 10 | Máximo: 500 | Step: 5
- Placeholder: "Ej: 80"
- Al escribir un número, el slider se mueve. Al mover el slider, el número se actualiza.
- Diseño: el input numérico grande y claro al lado del label, con botones [-] y [+] a los costados y flechitas nativas del input.

### Duración del evento (horas):
- Input numérico con flechas + botones [-] y [+].
- Mínimo: 1 | Máximo: 12 | Step: 0.5 (permitir medias horas como 3.5hs)
- Mostrar "hs" como sufijo al lado del input.
- Al costado, chips rápidos: "2hs" "3hs" "4hs" "5hs" "6hs" para selección rápida.

### Tipo de evento:
- Selector visual con 4 cards clickeables (no un dropdown):
  - 🍽️ Tranqui / Almuerzo
  - 🎉 Fiesta normal
  - 🔥 Fiesta intensa
  - 🎪 Festival
- La card seleccionada se resalta con borde dorado y fondo más claro.

### Temporada:
- Toggle switch estilizado con ícono:
  - ☀️ Verano (switch activado, color cálido)
  - ❄️ Invierno (switch desactivado, color frío/azul)

```

 Tipo   Cervezas Extras Datos  Resumen
  ✅      🔵      ⚪     ⚪      ⚪
```

- Paso completado: círculo dorado con check ✅

## 8. PULIDO VISUAL GENERAL

- **Sombras y profundidad**: agregar `shadow-lg` o `shadow-xl` a las cards principales para dar profundidad sobre el fondo oscuro.
- **Bordes sutiles**: las cards pueden tener `border border-white/10` para separarse del fondo sin ser agresivas.

- **Tipografía del precio total**: el precio total en el resumen debe ser grande, bold, color dorado, tal vez con un fondo highlight.
