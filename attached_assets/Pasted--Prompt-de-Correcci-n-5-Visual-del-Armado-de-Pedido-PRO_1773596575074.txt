## 1. STEPPER CON EFECTO DE CERVEZA LLENÁNDOSE

Reemplazar los círculos numerados actuales del stepper por **vasos/chopps que se van llenando de cerveza** a medida que avanzás en los pasos. La idea es que cada paso sea un vaso y cuando lo completás, el vaso se llena con cerveza ámbar y espuma arriba.

### Concepto visual:
```
Paso 1 completado    Paso 2 actual       Paso 3 futuro     Paso 4 futuro     Paso 5 futuro
   ┌───┐               ┌───┐               ┌───┐             ┌───┐             ┌───┐
   │███│ ☁️espuma       │▓▓▓│ ← llenando   │   │             │   │             │   │
   │███│ cerveza        │▓▓ │   animado     │   │             │   │             │   │
   │███│ lleno          │▓  │               │   │ vacío       │   │ vacío       │   │ vacío
   └───┘               └───┘               └───┘             └───┘             └───┘
   TIPO ✅             CERVEZA             CANTIDAD           EXTRAS            TICKET
```

### Implementación técnica:
- Cada "vaso" es un SVG o div con forma de vaso de cerveza (rectángulo con base más angosta, bordes redondeados arriba).
- **Paso completado**: el vaso está lleno de color ámbar/dorado (`#d4a017` o `#f59e0b`) con un detalle de espuma blanca arriba (borde blanco redondeado o pseudo-elemento). Checkmark ✅ pequeño debajo.
- **Paso actual**: el vaso se va llenando con una **animación de onda** que sube desde abajo. Usar una animación CSS tipo wave/liquid fill:
```css
@keyframes fillBeer {
  0% { height: 0%; }
  100% { height: 60%; }
}

@keyframes foam {
  0% { opacity: 0; transform: scaleY(0); }
  80% { opacity: 0; }
  100% { opacity: 1; transform: scaleY(1); }
}

@keyframes wave {
  0%, 100% { border-radius: 45% 55% 50% 50%; }
  50% { border-radius: 55% 45% 50% 50%; }
}
```
- **Paso futuro**: vaso vacío, solo el contorno en gris (`border-white/20`), sin relleno.
- **Línea entre vasos**: la línea que conecta los pasos también se "llena" de dorado hasta el paso actual (como si fuera un caño por donde fluye la cerveza). Usar un degradado que avanza.
- **En mobile**: mostrar solo el vaso del paso actual más grande, con texto "Paso X de 5 — Nombre del paso" y una barra de progreso debajo que también tenga textura de cerveza (fondo ámbar con efecto de burbujas sutiles).

### Ejemplo de barra mobile:
```
  🍺 Paso 2 de 5 — Elegí tu cerveza
  [████████░░░░░░░░░░░░]  40%
   ^ color ámbar con burbujitas
```

## 3. NAVEGACIÓN ADELANTE Y ATRÁS CLARA

Asegurar que en TODOS los pasos haya botones claros de navegación:

```
┌────────────────────────────────────────┐
│                                        │
│    (contenido del paso)                │
│                                        │
│   [← Anterior]         [Siguiente →]  │
│                                        │
└────────────────────────────────────────┘
```

### Reglas:
- **Paso 1**: solo mostrar "Siguiente →" (no hay anterior).
- **Pasos 2, 3, 4**: mostrar ambos "← Anterior" y "Siguiente →".
- **Paso 5 (resumen/ticket)**: mostrar "✏️ Modificar pedido" (vuelve al paso 1) y "📲 Enviar por WhatsApp".
- **El botón "Siguiente →"** debe estar deshabilitado (gris, no clickeable) si el usuario no seleccionó nada en el paso actual. Mostrar un tooltip o texto sutil: "Seleccioná al menos una opción para continuar".
- **El botón "← Anterior"** siempre habilitado.
- **Animación de transición entre pasos**: slide horizontal (al ir adelante el contenido sale por izquierda y entra por derecha, al ir atrás al revés). Usar `transition` o `framer-motion` si está disponible.
- En **mobile**, los botones de navegación deben ser sticky abajo de la pantalla para que siempre estén accesibles sin scrollear:
```
┌────────────────────────────────────────┐
│  [← Anterior]         [Siguiente →]   │
│              🛒 2 items · $92.000      │
└────────────────────────────────────────┘
```

## 5. DETALLE VISUAL: BURBUJAS DE CERVEZA DECORATIVAS

Agregar un efecto sutil de **burbujas de cerveza subiendo** como fondo decorativo de la sección "Armá tu pedido". Solo en el fondo, detrás del contenido, con opacidad muy baja para que no distraiga.

```css
@keyframes bubble {
  0% {
    transform: translateY(100%) scale(0.4);
    opacity: 0;
  }
  10% {
    opacity: 0.15;
  }
  100% {
    transform: translateY(-100%) scale(1);
    opacity: 0;
  }
}

.bubble {
  position: absolute;
  background: radial-gradient(circle, rgba(245, 158, 11, 0.3), transparent);
  border-radius: 50%;
  animation: bubble 6s infinite ease-in;
}
```

- Generar 8-12 burbujas de diferentes tamaños (8px a 24px) distribuidas aleatoriamente.
- Cada una con diferente `animation-delay` y `animation-duration` para que no se muevan sincronizadas.
- `pointer-events: none` para que no interfieran con los clicks.
- Solo visible en esta sección (overflow hidden en el contenedor).
