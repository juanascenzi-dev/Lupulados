## 2. AGREGAR MINUTOS AL CAMPO DE DURACIÓN DEL EVENTO

Actualmente solo se pueden elegir horas enteras. Necesito que se puedan elegir **horas y minutos** por separado, para cubrir eventos como "2 horas y media" o "3 horas 45 minutos".

Implementar con **dos selectores lado a lado**:

```
¿Cuánto dura el evento?

 Horas                Minutos
[-] [ 2 ▲▼ ] [+]    [-] [ 30 ▲▼ ] [+]

        = 2 horas 30 minutos
```

### Reglas:
- **Horas**: input numérico con botones [-] [+], mínimo 1, máximo 12, step 1.
- **Minutos**: input numérico con botones [-] [+], mínimo 0, máximo 45, step 15 (las opciones son 0, 15, 30, 45).
- Debajo de ambos inputs, mostrar un texto que diga la duración completa: "= X horas Y minutos" (o "= X horas" si los minutos son 0, o "= X hora 30 minutos" si es 1 hora con minutos).
- Si el usuario pone 0 minutos, no mostrar la parte de minutos en el texto.
- Los chips rápidos de duración (si los hay) deben incluir opciones con media hora:
  ```
  [2hs] [2:30] [3hs] [3:30] [4hs] [5hs] [6hs]
  ```
- Al seleccionar un chip, actualiza ambos inputs (horas y minutos).

### Cálculo:
- Para la lógica de la calculadora, convertir a horas decimales: 2hs 30min = 2.5 horas, 3hs 45min = 3.75 horas.
- Usar ese valor decimal en la fórmula que ya existe para calcular litros.
